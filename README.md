# Jornada — actualizaciones

Aquí se publican los instaladores de **Jornada**, la aplicación de control de tiempo para Mac (macOS 10.13 High Sierra o posterior).

- **Instalar**: descarga el `.dmg` de la [última versión](https://github.com/raizdedos/jornada-actualizaciones/releases/latest), ábrelo y arrastra Jornada a Aplicaciones.
- **Actualizar**: no hace falta hacer nada; Jornada avisa sola cuando hay una versión nueva (o menú *Jornada › Buscar actualizaciones…*).

Este espacio solo contiene los instaladores ya compilados.
